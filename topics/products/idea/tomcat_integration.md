# Tomcat Integration
<primary-label ref="IntelliJIDEA"/>

<link-summary>Information about Tomcat plugin source code location.</link-summary>

The source code of the Tomcat plugin included in IntelliJ IDEA is available as a sample for implementing application server integration plugins.
The code is located under <path>lib/src/src_tomcat.zip</path> in the main IntelliJ IDEA distribution.
